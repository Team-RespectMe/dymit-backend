## TASK-104 시간 포맷 대응
**STATUS** Done

## OBJECTIVE
최근 dymit backend 에서는 모든 시간 요청을 ISO8601 포맷의 UTC0 를 기준으로 요청/응답을 보내는 것으로 변경 하였습니다.
이로 인해 기존 버전에서 다음과 같은 형식으로 응답을 보내는 경우 문제가 발생하고 있습니다.
"2026-10-23T10:00:00.000"
처럼 끝에 Z가 붙지 않고 그냥 오는 경우 입니다.

이 경우 저 데이터가 KST 기준이라고 가정하고 저런 입력에 대해 Instant 객체에 요청 대입 시
2026-10-23T01:00:00.000Z 처럼 변환할 필요성이 있습니다.

## REQUIREMENTS
- 비지니스 로직은 수정하지 않습니다.
- config 패키지에 추가하여 해결할 수 있는지 확인하세요.
