## FEAT-108 내가 관리하는 그룹의 과제 목록 조회
상태: Done

## OBJECTIVE

내가 그룹 소유자인 그룹에 제출된 과제 중 제출 마감 일정이 오늘인 
과제 목록을 조회하는 API의 추가 요청이 왔습니다.
당신은 PM으로서 작업 계획을 수립해야 합니다.
기존 API들에 사이드이펙트가 없도록 새로운 엔드포인트를 추가하고
아래 요구사항을 달성하십시오.

## REQUIREMENTS
- 과제 목록은 내가 스터디 그룹장인 것들만 조회되어야 합니다.
- 마감 일정이 KST 기준 당일 0시부터 익일 0시 미만의 과제들이 조회되어야 합니다.
- 응답에는 프론트엔드에서 해당 과제를 클릭하면 그룹의 과제 상세 탭으로 이동할 수 있도록 그룹 정보(id, name), 과제(id, 제목) 이 포함되어야 합니다.
- 과제에는 미제출자 수가 카운트 되어야 합니다.
- 정렬 기준은 마감이 임박한 순으로 정렬되어야 합니다.
- 커서 페이지네이션이 적용되어야합니다. 커서 값은 쿼리스트링으로 cursor 전달되어야하며, 응답은 ListResponse 를 이용하여 래핑합니다. 
- 커서 파라미터들의 빌드는 기존 코드들의 사용 예를 참고하십시오.
