## TASK-62 과제 비지니스 제약 조건 검증
**STATUS** Done
**BACKGROUND**
과제 서비스 출시 전 비지니스 제약 조건이 제대로 구현되었는지 확인이 필요합니다.
### 과제 생성 제약 조건
- 과제에 연관된 스터디 일정의 시작 시점(schedule.scheduleAt)이 과제 생성 요청 시점보다 이전이라면 타입이 사전 과제로 자동 지정되어야 합니다.(요청 필드에 포함된 타입은 무시합니다.)
- 과제에 연관된 스터디 일정의 시작 시점(schedule.scheduleAt)이 과제 생성 요청 시점보다 이후라면 타입이 사후 과제로 지정되어야 합니다.
- 과제의 타입이 사전 과제로 지정된다면 과제 제출 대상자는 요청 필드를 무시하고 요청 시점의 일정 참여자 목록을 기준으로 생성되어야 합니다.
- 과제의 타입이 사전 과제로 지정된다면 과제 마감 시점이 일정 시작 시점으로 지정되어야 합니다. 
- 과제의 타입이 사후 과제로 지정된다면 과제 제출 대상자는 요청 필드를 기준으로 생성되어야 합니다.
- 과제의 타입이 사후 과제로 지정된다면 마감일은 제출된 마감일의 23:59:59초로 지정되어야 합니다. 단 요청 필드는 ISO8601 형식으로 UTC+9 으로 올 수도 있으나 서버 측에서는 UTC+0 으로 지정됨을 기억하십시오. 
### 과제 수정/삭제 제약 조건
- 과제의 마감일이 지난 경우 수정/삭제 할 수 없습니다.
- 과제의 마감일이 지나지 않은 경우 아래 조건을 만족해야합니다.
  - 과제의 제목은 변경이 가능합니다.
  - 과제의 설명(내용)은 변경이 가능합니다.
  - 과제의 첨부 파일은 변경 가능합니다.
  - 과제의 연관 일정은 변경 불가능합니다.
  - 과제의 제출 방식은 변경 불가능합니다.
## 과제 제출/삭제 제약 조건
- 마감 일정이 지난 과제는 제출/수정/삭제가 불가능합니다.
