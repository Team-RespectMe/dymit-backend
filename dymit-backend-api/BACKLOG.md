## FEAT-109 User Feed 기능 추가
**STATUS** Done

## OBJECTIVE

당신은 PM입니다. 현현재 

사용자 피드 API에 대해 다음 두 기능 추가가 요구됩니다.

1. 사용자의 Unread 상태의 한 유저 소유의 사용자 피드들의 수를 반환하는 엔드포인트가 필요합니다
2. 현재 Unread 상태인 한 유저의 사용자 피드들을 read 상태로 변경하는 엔드포인트가 필요합니다.

아래 요구사항을 분석하고 필요에 맞는 작업 계획을 의논 및 수립하여 서브에이전트들을 이용하여 구현합니다.

## REQUIREMENTS

- 현재 user feed 는 group feed 를 pull 해서 사용자 피드에 포함하는 로직이 존재합니다.
  마찬가지로 unread count 계산 시에도 그룹 피드를 먼저 pull 하여 사용자 피드에 포함시킨 뒤 계산해야합니다.
- Unread 상태인 사용자 피드를 read 로 변경하는 것은 효율성을 위해 매 엔티티를 불러 처리하지말고 쿼리 한번에 변경하도록 합니다. 
- Persistence Layer의 Port는 해당 도메인 패키지에 이미 존재합니다. 해당 Load/Save Port 에 메서드를 추가하여 처리할지 별도 포트로 나눌지는 
  판단 후에 의견을 제시하고 제 답변을 듣고 진행합니다.
