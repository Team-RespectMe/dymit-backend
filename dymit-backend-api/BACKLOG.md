## FEAT-109 사용자 일정 API 비지니스 로직 수정
**STATUS** Done

## OBJECTIVE

당신은 PM입니다. 사용자 주간 일정 및 일간 일정 비지니스 로직에 변경 요구사항이 들어왔습니다.

**현황**
- 현재 주간 일정에서 일정 존재 여부는 해당 일에 내가 참여 중인 스터디 일정이 있거나, 내가 제출 대상인 과제가 있는 경우 true로 반환합니다.
- 일간 일정 조회 시 내가 참여중인 스터디 일정에 대해서만 정보를 반환합니다.

**변경 요구사항**
- 주간 일정에서 일정 존재 여부 판별 시 스터디 일정의 경우 내가 가입한 그룹의 스터디 일정이 존재하는지 여부로 변경합니다.(참여 여부는 고려하지 않습니다.)
- 일간 일정 조회시에도 마찬가지로 스터디 일정은 내가 가입한 그룹의 스터디 일정이 존재하면 보여주는데 대신 일정 참여자 수 그리고 내 참석 여부를 같이 표기해줘야 합니다.

## REQUIREMENTS
- 일간 일정 조회 시 STUDY_SCHEDULE 타입에 참석자 수, 내 참석 여부 에 대한  변수 명을 저와 상의하십시오.
- 사이드 이펙트가 없도록 작성하세요.
