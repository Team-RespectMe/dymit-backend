## TASK-106 주단위 일정 조회 API
상태: Done

## OBJECTIVE

사용자가 속한 스터디 그룹의 이벤트를 주 단위로 조회하되, 각 요일별로 이벤트의 존재 여부를 파악할수 있는 API를 제공해야합니다.
기존 API 요청 / 응답 패턴(데이터 패턴 및 요청 패턴 모두 포함)을 충분히 고려하여
아래 요구사항을 달성하십시오.

## REQUIREMENTS
- 주간 일정은 기본적으로 일요일을 그 주의 시작으로 고려합니다.
- 조회 시 주 단위로 조회 요청이 가능해야합니다.
- 해당 주의 7일 동안 사용자가 속한 그룹에 이벤트가 있는지 여부를 파악하여 일정이 있는 날에 일정이 있음 정도만 표기하면 됩니다.
- API 사용자가 최초대한 쉽게 요청 할 수 있는 방식이면 좋겠습니다.
- 이 기능은 어떤 도메인에 속해야하는지 먼저 판단하십시오.
- 엔드포인트 디자인을 하십시오.
- calendar 도메인으로 확정하고 아래 사항을 고려하여 작성하십시오. 
- calendar 도메인에 속하지 않는 데이터는 해당 패키지 내부에 out port 에 따로 Load~Port  등을 정의하여 가져와야합니다. 
- 기존 패키지 구성 패턴을 참고하십시오. 불필요한 오버 엔지니어링은 금지합니다. 
- 주간 응답은 날짜별 이벤트 존재 여부만 반환합니다. 상세 이벤트와 그룹은 포함하지 않습니다.
- 일간 응답만 상세 이벤트 목록을 반환하며 각 이벤트에 group: { id, name }을 포함합니다. 
- 일간 이벤트는 그룹별 중첩 없이 평탄한 목록으로 반환합니다.
- 정렬은 애플리케이션 레이어에서 groupId 오름차순, eventAt 내림차순으로 수행합니다.
- 과제는 로그인 회원이 제출 대상인 과제만 포함합니다.
- 스터디 일정은 로그인 회원이 참가 등록한 일정만 포함합니다.
이 기준으로 작업 계획을 수립하고 서브 에이전트를 이용하여 작업을 수행해주십시오.

## Important
- 쓸데없이 복잡도 높이는 오버 엔지니어링 하지 마십시오.
- 패키지 레이아웃을 유지하십시오.
