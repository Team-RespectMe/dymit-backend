## FEAT-109 그룹 통계 및 그룹 구성원 통계 계산 방식 검증
**STATUS** Done

## OBJECTIVE

당신은 PM입니다. 

최근 추가된 스터디 그룹의 지표 계산에 대한 계산 방식을 검증해야합니다.
현재 제가 의도했던 계산 조건은 다음과 같습니다.

- 모든 통계는 Lazy하게 계산된다. 이미 계산된 정보가 있다면 그냥 반환하지만 없다면 조회 시점에 계산하여 반환한다.
- 개인이 자신의 통계를 조회하는 경우에도 동일하게 Lazy하게 반영된다.
- 그룹 구성원들에 대한 통계 수치의 경우 개인이 현재 조회하지 않아 구성된 통계값이 없다면 그룹 구성원 통계 목록 조회 시 일괄적으로 계산한다.
- 일정 참여율 계산은 다음과 같은 조건을 추가로 고려하여 계산한다.
  - 내가 그룹 가입을 한 이후 scheduleAt 이 존재한 일정에 대해서만 계산한다.
  - 조회 시점에 완료된 일정에 대해서만 계산한다.
  - 즉 참여율은 (내가 참여한 일정 수 / 내가 가입한 시점 이후에 일정이 예정된 스터디 일정 중 완료된 것들의 수 ) * 100 으로 계산되어야 한다.
- 과제 제출율은  조회 시점에 마감 일정이 지났고, 내가 과제 제출 대상인 과제에 대해서 계산을 진행해야한다.
